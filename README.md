# CodeOrbit Task 1: Data Preprocessing & Exploratory Data Analysis (EDA)

## Project Overview
This project is part of the Machine Learning Internship at CodeOrbit Tech. It uses Python and the Iris dataset to demonstrate data preprocessing and Exploratory Data Analysis (EDA).

## Objectives
- Explore the structure and features of a dataset.
- Check for missing values and handle them when necessary.
- Identify and remove duplicate records.
- Generate descriptive statistics.
- Detect potential outliers using the Interquartile Range (IQR) method.
- Visualize data distributions and relationships between features.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses the Iris dataset, which contains measurements for three flower species: Setosa, Versicolor, and Virginica. The numerical features include sepal length, sepal width, petal length, and petal width.

## Project Workflow
1. Load the Iris dataset.
2. Inspect the dataset using its first rows, shape, and column information.
3. Check for missing values.
4. Handle missing values where necessary.
5. Identify and remove duplicate records.
6. Review descriptive statistics.
7. Examine the distribution of flower species.
8. Identify potential outliers using the IQR method.
9. Create histograms, scatter plots, and a correlation heatmap.
10. Summarize the findings.

## Visualizations
- **Histograms:** Explore the distribution of numerical features.
- **Scatter plots:** Examine relationships between flower measurements.
- **Correlation heatmap:** Review correlations between numerical features.

## How to Run
### 1. Install the required libraries
Open a terminal in the project folder and run:

```bash
python -m pip install pandas matplotlib seaborn scikit-learn
```

### 2. Run the Python script
Make sure the script is saved in the current folder. If its name is `CodeOrbit_Task_1_Data_Preprocessing_and_EDA.py`, run:

```bash
python CodeOrbit_Task_1_Data_Preprocessing_and_EDA.py
```

If you saved the script with a different filename, replace the filename in the command with your actual filename.
